# Farm Pond Watch Project Report Site

This is a static GitHub Pages-ready project report site for NSF Award #2429932:

**EPSCoR Research Fellows: NSF: Farm Pond Watch: A framework for monitoring subseasonal dynamics of farm ponds to enhance water resource resilience**

The site also includes the related benchmark dataset:

**SWD-Net: A Benchmark Dataset for Small Water Body Detection from Very High-Resolution Imagery**

## Files

- `index.html`: Page structure and project report content
- `styles.css`: Visual design and responsive layout
- `script.js`: Award metric animation
- `.github/workflows/deploy.yml`: GitHub Pages deployment workflow
- `.nojekyll`: Prevents GitHub Pages from processing files with Jekyll

## Publish to GitHub Pages

1. Create a GitHub repository, for example `farm-pond-watch-report`.
2. Upload all files in this folder to the repository root.
3. Open repository `Settings`, then go to `Pages`.
4. Under `Build and deployment`, choose `GitHub Actions`.
5. Push to the `main` branch and wait for the deployment workflow to finish.
6. GitHub will show the public Pages URL after deployment.
